# Quiz Vault 📚

> ⚠️ **Windows Only** — Quiz Vault currently runs on Windows desktop only. Mac and Linux support is not yet available.

Quiz Vault is an AI-powered quiz manager built for students. Generate mock quizzes with AI, organize them by subject, and take them — all in one place.

---

## ✨ What You Can Do

### 🤖 Generate Quizzes with AI
Use the built-in **Prompt Builder** to create a ready-to-copy prompt for any AI (ChatGPT, Gemini, etc.). Customize:
- Number of items
- Difficulty level
- Question style (Situational, Problem Solving, or Mixed)
- Support for math equations (LaTeX) and reference tables

Once the AI generates your quiz, download it as a JSON file and import it into Quiz Vault — it handles the rest.

### 🧠 Generate from Your Own Notes (RAG)
Have lecture notes or handouts? Upload them directly — no copy-pasting needed.

Quiz Vault's built-in **RAG (Retrieval-Augmented Generation)** system reads your uploaded files and uses them as context when generating quizzes, so questions are based on *your actual material*, not just general knowledge.

- Supports **PDF** and **TXT** files
- Uses **Ollama** for local, offline embeddings — your notes never leave your computer
- Or connect **OpenAI / Gemini Flash** for faster cloud-based generation
- Works fully offline if you prefer

### 🗂️ Organize Your Quizzes
Keep everything tidy with a familiar folder-based sidebar (think VS Code's file explorer):
- Create folders per subject or course
- Rename and move quizzes freely
- Use the search bar to find any quiz instantly
- Unfinished quizzes are automatically saved to a **Drafts** folder

### 📝 Take Quizzes Your Way
Two modes to fit how you study:
- **Default Mode** — Standard quiz experience, results at the end
- **Practice Mode** — Get instant feedback after every question

Other options:
- Set a custom timer ⏱️
- Shuffle questions and answer choices 🔀
- Full support for math equations and data tables in questions

### ✏️ Build or Edit Quizzes Manually
Prefer making your own? The quiz editor lets you:
- Add Multiple Choice, True/False, and Fill-in-the-Blank questions
- Edit metadata (title, category, difficulty)
- Auto-saves as you work — no lost progress

### 📊 Track Your Progress
- See your mastery level per quiz with visual progress bars
- Get a high-level view of your quiz library's difficulty breakdown

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl / Cmd + N` | Create a new quiz |
| `Ctrl / Cmd + O` | Open your quiz library |
| `Ctrl / Cmd + W` | Go to the Welcome page |

---

## 🚀 Getting Started

> **Requirements:** Windows 10 or later. Mac and Linux are not currently supported.
1. Use the **Prompt Builder** to generate your first quiz, or create one from scratch in the **Editor**
2. *(Optional)* Upload your lecture notes via the RAG system to generate quizzes from your own material
3. Create folders in the sidebar to organize by subject — and start studying!
